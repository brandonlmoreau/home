# Home

Phone home screen for personal apps.

## Apps

| App | Open |
| --- | --- |
| [Construction Tracker](./construction-tracker/) | Clock in / out, Monday–Sunday week totals, past-week history |

## On Android

1. Open this site in Chrome
2. Menu → **Add to Home screen** / **Install app**
3. Tap **Construction Tracker** from Home

Hours for Construction Tracker are saved in the phone browser. Use **Download backup** inside that app for a JSON copy, or **Download app file** for a standalone HTML.
